# 原版郊狼 V2 蓝牙直连 · Windows 实测指南

> 给想在自己电脑上连上**老版郊狼（DG-LAB V2 / Coyote，机器本身只有蓝牙、没有手机 App）**的用户看。
> 这份指南假设你已经装好了本客户端的 Windows 版（或 Windows / Linux 上的桌面客户端，底层是 Chromium 内核）。

---

## 一、哪些机器能用这个功能？

- ✅ **能用**：原版 V2 硬件（DG-LAB Coyote、D-LAB ESTIM01、YSKJ 系列等只走蓝牙的机器）。
- ❌ **用不了**：新版郊狼（靠手机 App「娱乐模式」连的那种）——那种走的是另一种「App 中转」方式，在软件里选「App 娱乐模式」即可，和本指南无关。
- ⚠️ **平台限制**：蓝牙直连依赖系统的 Web Bluetooth。
  - **Windows / Linux / Android**：可用。
  - **macOS（苹果电脑）**：系统限制，浏览器蓝牙不可用。Mac 上请继续用「App 娱乐模式（WebSocket）」方式连新版。

---

## 二、连接步骤（一步一步来）

1. **开机并让机器进入可被发现状态**
   把 V2 机器通电，按一下机身配对键（具体看你的机型说明书），让蓝牙处于「可被发现」。

2. **打开客户端 → 品牌设备页**
   在左侧边栏点「品牌设备」，进入后默认在「郊狼 DGLab」标签页。

3. **选「蓝牙直连」**
   页面上方有一组单选：**App 娱乐模式（WebSocket）** / **蓝牙直连（V2）**。
   选 **蓝牙直连（V2）**。

4. **点「扫描并连接」**
   客户端会弹出系统的蓝牙设备选择框（这是浏览器/系统原生弹窗，不是软件自己画的）。
   在列表里找你的机器（名字通常带 `D-LAB` / `DG-LAB` / `COYOTE` / `YSKJ` / `ESTIM` 字样），点它，再点「配对 / 连接」。

5. **连上了**
   连上后设备会出现在下方「已连接设备」里，并自动进入 V2 控制面板。

---

## 三、控制面板怎么用

连上后你会看到：

- **通道 A / B 强度**：各一个滑块（0–100）。软件会按 0–100 自动映射到机器内部的 0–2047 强度。
- **通道 A / B 波形**：频率 X（0–31）、强度 Y（0–1023）。机器实际频率 = X + Y。一般先把 X、Y 拉到中间位置试。
- **电量**：显示当前机器电量百分比。点「读取电量」可刷新。
- **应用 / 停止**：拉好强度波形后点「应用」下发；「停止」把强度归零。

> 小提示：第一次玩**先从很低强度开始**，确认手感和安全后再慢慢加。

---

## 四、强度「位排布」是什么？要管吗？

老版 V2 有两份互相矛盾的资料：一份是官方文档，一份是网上开源爱好者的参考代码。它们对「强度数字怎么塞进蓝牙数据包」写得不一样。

软件默认用**开源参考写法（`coyote2`）**。但**最终哪种对，得拿你的真机器试**。

控制面板里有一个下拉：**强度位排布（标定用）**，两个选项：
- `coyote2（经验参考，默认）`
- `official（官方文档）`

**怎么标定**：
1. 选一个布局，应用一个中等强度（比如 50）。
2. 看机器实际震动强度是否符合预期（大致线性、不过猛也不过弱）。
3. 如果感觉明显不对（比如强度乱跳、和滑块不成比例），切到另一个布局再试。
4. 找到正确的那个后，软件会**记住你的选择**（存在浏览器本地，下次自动用）。

> 这个开关是运行时即时生效的，不需要重启软件、也不需要改任何配置文件。

## 五、常见问题

| 现象 | 可能原因 / 处理 |
| --- | --- |
| 点「扫描」没弹出设备框 | 系统蓝牙没开；或机器没进入可被发现状态。先开系统蓝牙、按机器配对键。 |
| 列表里找不到机器 | 机器广播名不含关键字。确认机器确实在配对模式；可重试扫描。 |
| 连上后强度完全不对 / 乱跳 | 见第四节，切换「强度位排布」再试。 |
| macOS 上「蓝牙直连」点了没反应 | 苹果电脑的浏览器限制蓝牙，此功能在 Mac 不可用，请用「App 娱乐模式」。 |
| 应用时报错 | 设备可能已断开（电量耗尽 / 超出距离）。回到设备列表刷新、重连。 |

## 六、给开发者的话

- 后端接口：`GET/POST /api/brands/v2-layout` 读取 / 切换位布局；`/api/brands` 下其余控制接口同既有品牌框架。
- 协议细节与标定说明见同目录 `README.md` 的「形态 1：原版 V2 蓝牙直连」一节。
- 设备以 `brandBle` 传输类型注册进 `deviceService`，因此可被设备映射、玩法复用同一套 `shock`/`strength` 能力驱动。
