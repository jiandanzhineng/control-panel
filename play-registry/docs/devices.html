设备与能力

声明玩法所需设备 · 对照后端 backend/devices/registry.js

玩法在 manifest 的 devices[] 里声明逻辑设备及其所需能力。启动时用户在面板 UI 把逻辑设备映射到真实物理设备；宿主按能力校验：required=true 的逻辑设备必须映射、已映射设备必须在线且同时满足声明的全部能力。

声明设备需求

"devices": [
  { "id": "sensor",  "capabilities": ["sphincterPressure"], "required": true },
  { "id": "motor",   "capabilities": ["strength"],          "required": true },
  { "id": "punish",  "capabilities": ["shock"],             "required": false }
]

required: false 的设备是可选的——玩法代码里用 device(id).isMapped() 判断后再调，匹配不到就走降级分支。

能力详解

strength — 强度控制

控制电机功率。set 的 value 范围 0–255。下行广播到所有映射电机。

DeviceAPI.device('motor').invoke('strength', 'set', { value: 128 });

shock — 电击控制

start(voltage) 开始电击，stop() 停止。建议 voltage 不超过 30V（玩法可声明 allowUnsafeIntensity 参数放开）。

DeviceAPI.device('punish').invoke('shock', 'start', { voltage: 30 });
// …
DeviceAPI.device('punish').invoke('shock', 'stop');

sphincterPressure / tiptoePressure — 压力上报

纯上行能力，无下行动作。连续数值应通过 readValue / onValue 读取，避免依赖底层属性名。CUNZHI01 的踮脚值来自真实 pressure1；QTZ 任一脚踏按钮为 1 时派生值 200，否则为 0。QTZ 的 0/200 是兼容阈值逻辑的模拟状态值，不代表 kPa。

const initial = await DeviceAPI.device('sensor').readValue('tiptoePressure');
DeviceAPI.device('sensor').onValue('tiptoePressure', (value, oldValue) => {
  console.log('踮脚压力:', oldValue, '->', value);
});

buttonInput — 按钮输入

三个事件：pressed（短按）、pushDown（按下）、pushUp（松开）。底层是设备消息，能力层封装为统一事件。

DeviceAPI.device('qtz').on('buttonInput', 'pushDown', () => onPushDown());
DeviceAPI.device('qtz').on('buttonInput', 'pushUp',   () => onPushUp());

distance — 距离检测

configure 设置近/远阈值带和上报间隔；事件 enterLow（进入近带）、enterHigh（进入远带）。

DeviceAPI.device('qtz').invoke('distance', 'configure', { lowBand: 20, highBand: 80, reportDelayMs: 200 });
DeviceAPI.device('qtz').onValue('distance', (value) => console.log(value));

lock — 锁控制

DeviceAPI.device('lock').invoke('lock', 'setOpen', { open: true });  // 开锁
DeviceAPI.device('lock').invoke('lock', 'setOpen', { open: false }); // 关锁

weight — 重量上报

纯上行，通过 readValue('weight') / onValue('weight') 读取当前值与变化。

reporting — 上报频率

调节传感器上报间隔（毫秒）。压力大或需要精细响应时调小，省电时调大。

DeviceAPI.device('sensor').invoke('reporting', 'setReportDelay', { ms: 200 });

能力事件 trigger 的 data

能力事件的 data 含 props（属性快照）、changed（变化属性 key）、msg（消息对象，消息类事件才有）。watch 支持混合监听属性和消息，能力层屏蔽底层差异——你只关心能力级事件，不用管属性名或 MQTT 消息格式。

🔒

所有设备类型都声明 close 操作定义安全停机指令（电机归零、停止电击、传感器恢复空闲频率）。会话结束时宿主强制调用，独立于玩法逻辑——这是设备安全的最后一道防线。
