# surge-edging 测试文档

- 游戏 ID：surge-edging
- 游戏版本：1.1.2
- 所需设备：QIYA（sphincterPressure + reporting，必需）、TD01（strength，必需）；DIANJI（shock，可选）、ZIDONGSUO（lock，可选）
- 测试方式：虚拟设备（`tools/vdev-cli` 或 REST 注入 pressure）、实机输出观察
- 时间允许误差：±300ms
- 运行说明：页面加载即自动开始（无开始按钮）；`duration` 到期自动结束。背景参考 [游戏运行时](../../../docs/requirements/Game_Runtime.md)、[设备能力](../../../docs/device/capabilities.md)、[Electron 调试](../../../docs/guides/ELECTRON_DEBUG.md)、[虚拟设备工具](../../../tools/vdev-cli/README.md)。

## 整体玩法原则

- P1：平静期强度随时间缓升（每秒 +`gradualIncrease`），电机按 `sendIntervalMs` 上限周期收到最新强度。
- P2：气压双窗口突变——本窗口 [-τ,0] 最大值 − 前一窗口 [-2τ,-τ] 平均值 ≥ `surgeRiseKpa`（默认 500ms/1.0kPa）且保持 ≥ `minSurgeMs`（100ms）→ 进入边缘期。抬升不足阈值不触发；单个尖峰采样会在 W1 最大值窗口内存留约 τ，同样视为有效突变。
- P3：进入边缘期时电机强度立即归零（归零命令不受限速、立即下发），并恰好输出一次电击（默认 20V / `shockDuration` 秒后自动 stop）。边缘期内保持压力不会重复电击。
- P4：气压回落到触发时基准（突变前窗口均值）+0.2kPa 以下 → 退出边缘进冷却（`lowPressureDelay` 秒）；边缘期超过 `maxEdgeSec`（默认 5s）强制进冷却。
- P5：冷却期满回平静期，强度按 `maxMotorIntensity·(中间压−当前压)/中间压` 起步继续缓升；冷却期内不监测突变。
- P6：中间压自适应：每次进入边缘期更新为 max(本次触发峰值 − `midOffsetKpa`, 上轮冷却期最低压 +1)。压力升到中间压以上进中期，中期强度随压力从 dmax（默认 20）线性降到 dmin（默认 5）；压力回落中间压以下回平静期。
- P7：暂停时强度立即归零；恢复后清空突变检测窗口，不用暂停前的旧基准误触发。
- P8：游戏结束时电机归零、停止电击、开锁、传感器上报间隔恢复 5000ms；手动停止/关页由宿主按 ADR-0004/0005 兜底复位。
- P9：电击/锁未映射时游戏正常运行，跳过对应命令，不报错。

## 观察项

- 游戏状态：平静期 / 中期刺激 / 边缘寸止 / 冷却延迟（页面状态文字、`window.__game.rt.state`）
- 传感器输入：sphincterPressure（kPa，虚拟设备 `pressure` 属性）
- 设备输出：
  - `motor.strength.set {value}`——整数，限速下发（≤1 条/`sendIntervalMs`）；归零为紧急命令立即下发
  - `punish.shock.start {voltage}` / `punish.shock.stop {}`——边缘触发一次，`shockDuration` 秒后自动 stop
  - `lock.setOpen {open:false}`（开始时）/ `{open:true}`（结束时）
  - `sensor.reporting.setReportDelay {ms:100}`（开始）/ `{ms:5000}`（结束）
- 用户反馈：状态文字、日志列表（`#logs`）、7 段语音、双轴图表（压力 + 强度 + 边缘标记）

## 公共准备

- 映射：`sensor→QIYA 虚拟设备`、`motor→TD01 虚拟设备`；T01–T11 另映射 `punish→DIANJI`、`lock→ZIDONGSUO`。
- 虚拟设备创建（`pressure` 初始 10，`report_delay_ms:100`），命令记录用 `GET/DELETE /api/virtual-devices/{id}/commands`。
- 测试参数（缩短周期便于观察）：

  ```
  duration=5, endCalmLock=0, surgeWindowMs=500, surgeRiseKpa=1.0, minSurgeMs=100,
  midOffsetKpa=1.0, maxMotorIntensity=50, lowPressureDelay=2, maxEdgeSec=5,
  sendIntervalMs=500, rampRate=2, gradualIncrease=2, randomPercent=0,
  midIntensityMin=5, midIntensityMax=20, shockVoltage=20, shockDuration=3, voiceEnabled=false
  ```

- 压力注入要点（关键）：
  - 虚拟设备属性**值不变不产生 update 事件**，必须逐步微变（如 10.0/10.1 交替），间隔约 110ms；
  - 双窗口 τ=500ms，触发突变前需先注入 ≥10 个低位采样铺满 2τ；
  - 低位基准：10.0/10.1 交替；突变：10.5→11.2→12.0→12.8→13.5 递增；泄压：10.0→9.5→9.0→8.8→8.5。
- 每个场景开始前重启游戏（重载游戏 iframe 或重新进入运行页）并清空两台设备的命令记录。
- 实机执行相同场景：只观察设备下行输出，不连接人体。

## 测试场景

### T01：平静期缓升

- 验证原则：P1
- 当前状态：游戏刚启动，平静期，压力 10，强度 0。
- 输入变化：注入 10.0/10.1 交替采样 3 秒。
- 预期状态：保持平静期（10 < 初始中间压 50）。
- 预期输出：启动序列下发 `strength 0`、`lock.setOpen(false)`、`shock.stop`；随后 motor strength 命令值递增（≈每秒 +2），速率 ≤1 条/500ms。
- 违规条件：强度不升或超过 maxMotorIntensity；命令速率超限；出现 `shock.start`。

### T02：突变触发边缘

- 验证原则：P2、P3
- 当前状态：平静期，低位窗口已铺满（≥10 个采样 @10）。
- 输入变化：1 秒内递增注入至 13.5（W1max−W2avg ≈ 3.5 ≥ 1.0）并保持 1 秒。
- 预期状态：进入边缘寸止，edgingCount=1。
- 预期输出：强度立即归零（归零命令立即下发，不受 500ms 限速）；恰好一次 `punish.shock.start {voltage:20}`，3 秒后一条 `shock.stop`。
- 违规条件：未进边缘；归零命令延迟超过限速间隔；无电击或多于一次 `shock.start`。

### T03：抬升不足阈值（边界）

- 验证原则：P2
- 当前状态：平静期，低位窗口已铺满 @10。
- 输入变化：递增注入至 10.6（差 0.6 < 1.0）并保持 2 秒。
- 预期状态：保持平静期，edgingCount=0。
- 预期输出：无 `shock.start`；强度继续缓升。
- 违规条件：进入边缘或输出电击。

### T04：边缘保持不重复电击

- 验证原则：P3
- 当前状态：已进入边缘期（T02 之后），压力 13.5，已输出一次电击。
- 输入变化：保持 13.5 持续 3 秒（< maxEdgeSec 5s）。
- 预期状态：保持边缘期。
- 预期输出：`shock.start` 仍只有 1 次；强度保持 0。
- 违规条件：重复电击；强度 >0。

### T05：泄压退出进冷却

- 验证原则：P4
- 当前状态：边缘期，压力 13.5。
- 输入变化：注入 10.0→9.5→9.0→8.8→8.5（每步 110ms），回落到触发基准+0.2 以下。
- 预期状态：进入冷却延迟。
- 预期输出：强度保持 0；无新电击。
- 违规条件：仍处边缘期；强度非 0。

### T06：冷却期满回平静

- 验证原则：P5
- 当前状态：冷却延迟开始，压力 8.5。
- 输入变化：保持 8.5 并等待 `lowPressureDelay` 2 秒。
- 预期状态：回到平静期；强度重新缓升（起步 ≈ 50×(12.5−8.5)/12.5 = 16）。
- 预期输出：motor strength 重新出现递增命令。
- 违规条件：冷却内进入边缘；冷却后强度不恢复。
- 备注：冷却期内注入突变采样不应触发边缘（DELAY 不监测突变）。

### T07：边缘超时强制冷却

- 验证原则：P4
- 当前状态：边缘期，压力持续 13.5。
- 输入变化：保持 13.5 超过 `maxEdgeSec` 5 秒。
- 预期状态：5 秒后强制进入冷却延迟，日志出现「边缘期超时(5s)，强制进入冷却」。
- 预期输出：强度保持 0。
- 违规条件：卡死在边缘期；超时窗口超出 ±300ms。

### T08：中间压自适应与中期

- 验证原则：P6
- 当前状态：已至少经历一次边缘（中间压已从 50 更新为 ≈ 峰值−1，如 13.5−1=12.5），当前冷却结束回平静。
- 输入变化：压力注入升至 12.8（> 中间压 12.5）保持；再注入 13.6（≥ 中间压+ΔP=13.5）；最后回落 12.3。
- 预期状态：依次进入中期；压力回落中间压以下回平静期。
- 预期输出：中期强度从 dmax=20 随压力线性降至 dmin=5；不触发电击（除非再次突变）。
- 违规条件：中期强度不随压力下降；中间压未按 max(峰值−偏移, 上轮最低+1) 更新。

### T09：暂停与恢复

- 验证原则：P7
- 当前状态：平静期运行中，突变窗口已有旧采样。
- 输入变化：点击暂停 → 立即检查输出；再点击继续，恢复后 1 秒内注入一次 13.5 尖峰（不重铺窗口）。
- 预期状态：暂停时游戏停摆；恢复后正常运行。
- 预期输出：暂停瞬间 `strength 0` 立即下发；恢复后因窗口被清空，W2 无采样时不应触发边缘（需重新铺窗口后才可触发）。
- 违规条件：暂停期间强度 >0；恢复后用暂停前旧基准误触发边缘。

### T10：结束复位

- 验证原则：P8
- 当前状态：游戏运行中（`duration` 设 1 分钟），已加锁。
- 输入变化：等待时长到期。
- 预期状态：「已结束」，日志「结束（边缘 N 次，电击 M 次）」。
- 预期输出：`motor strength 0`、`punish.shock.stop`、`lock.setOpen(true)`、`sensor.reporting.setReportDelay {ms:5000}` 逐一下发。
- 违规条件：任一设备未复位。

### T11：可选设备缺失

- 验证原则：P9
- 当前状态：仅映射 sensor 与 motor，不映射 punish/lock。
- 输入变化：执行与 T02 相同的突变流程。
- 预期状态：正常进入边缘期并走完冷却。
- 预期输出：无任何 punish/lock 命令；页面无报错、不白屏。
- 违规条件：报错；状态机中断；尝试调用未映射设备导致异常。
