# 面板与游戏 i18n

- 面板先做中英（P0 骨架 + P1 英文），日/韩/西后置。
- 内置游戏 `index.html` 的 `game-manifest` 可带 `i18n.en`（title/description/howTo/devices/params/enumLabels/paramDescriptions/paramUnits）。面板列表和配置页按当前语言覆盖中文顶栏字段。
- 游戏页内 UI 读 `DeviceAPI.locale`；静态文案用 `data-en`，JS 用中文当 key 调 `GameI18n.t()`，其它语言放游戏自己的 `i18n.js`。运行中不热切，重进再生效。
- play-registry 用户页（首页/列表/控制/运行壳）中英跟随浏览器语言，右上角可手动切换，记在 `localStorage.site-locale`。开发文档正文可仍中文，导航与页脚随站点语言。
- 游戏日志/语音文件/协议值不翻译。
