# 游戏库合并本地与在线游戏

用户要求重构 PC 游戏列表页：能力需求是英文、在线游戏衔接不流畅、缺少设计感，可调整游戏站嵌入方式。

- 菜单「本地游戏」改为「游戏库」：本机游戏、在线库游戏（`/api/game-registry`）、插件、本机应用在一页列出，同 id 只出一张卡；在线版本更高时标「可更新」并从在线启动。
- 在线游戏点「开始」直接进配置页（`source=remote`），不必再进网页找游戏。
- 菜单「在线游戏」改为「游戏站」，作社区、投稿、文档入口，跟随客户端语言；游戏卡可直达其介绍页。
- 设备需求显示设备角色中文名，能力名一律本地化，游戏站页面同样本地化能力名。

方案见 `docs/plans/game-library-redesign.md`。
