# 游戏库测试分类、投稿/建议入口与自绘标题栏

用户要求优化 PC 端游戏库与窗口外观：

- 测试用的游戏单独放「测试」分类，不在「全部」「本机」「在线」里显示，也不进「继续上次」。目前包括 Game Platform QA、心率探针（联调）、设备控制台；manifest 标 `test`、id 以 `qa-`/`zz-` 开头、标题含「联调/测试/QA」的自动归入。
- 游戏库顶部加「投稿游戏」「玩法建议」按钮，都标「采纳有奖」。投稿指向游戏站投稿页；玩法建议走商城工单系统（与商城反馈是同一套），客服页的反馈入口也统一到商城工单。
- 左侧菜单删掉「游戏站」，只保留游戏库页顶部一个入口。
- 去掉 Windows 原生标题栏，改为与侧栏一体的自绘标题栏，要有设计感。
