# DeepSeek Harness（dsh）插件：让 AI agent 控制设备与客户端

面向用户的成品功能，以 cordis 插件形式发布，插件代码独立仓库（不进主仓），主仓只补通用接口。

- 只连本机 PC 端；可控本机设备，以及本机作为主控端时已获授权的远程投影设备。
- 尽量开放全部客户端能力：窗口、页面跳转、启停游戏与参数、设备连接等，允许 agent 自由控制。
- 允许 agent 自己写脚本，在插件沙箱里执行；agent 可自行订阅设备/游戏事件，由事件自动触发脚本或唤醒 agent。
- 强度安全：用户在插件设置里给阈值，超过阈值的指令自动缩放到阈值，未超过的直接放行，不弹确认。
- 会话结束是否自动停止所有设备由用户在设置里选。
- 急停随时可用、免确认；所有 agent 发出的控制指令记审计日志。
- 测试默认用虚拟设备。

方案见 plans/dsh-agent-plugin.md。
