# 原生背单词游戏

PC/手机共用，保留扇贝插件。

- 英文单词四选一中文释义，另有「不认识」，自动朗读单词。
- 选错、超时（默认 20 秒）、不认识都电击，不加码；答案显示 10 秒后自动下一题，也可点或说「继续」提前进入，该词排到当天队尾。
- 词库：高考、四级、六级、雅思，来源 ECDICT，跨词库共用进度。
- 每天若干新词（默认 20）加到期旧词。旧词当天首次答对，间隔翻倍（1、2、4、8……天，不封顶）；答错回到 1 天。
- 可选自动锁：当天新词和复习做完才解锁；整体时限到也结束并解锁。
- 默认开启语音，说「第一个」到「第四个」选择；也能点选或手动关闭语音。
- 进度走账号云同步，必须登录。
