# 原生背单词游戏

自制背单词游戏替代扇贝网页插件（插件保留）。先做 PC，兼容手机。

- 每题一个英文单词，4 个中文释义选 1，另有「不认识」。只做英选中，自动朗读单词。
- 选错、超时（默认每题 20 秒）、不认识都电击，不加码；显示正确答案，点「继续」往下，该词排到当天队尾。
- 词库：高考、四级、六级、雅思，来源 ECDICT，跨词库共用进度。
- 每天若干新词（默认 20）加到期旧词。旧词当天首次答对，间隔翻倍（1、2、4、8……天，不封顶）；答错回到 1 天。
- 可选自动锁：当天新词和复习做完才解锁；整体时限到也结束并解锁。
- 语音模式：说「第一个」到「第四个」选择。
- 进度走账号云同步，必须登录。
