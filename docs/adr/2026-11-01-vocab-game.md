# 原生背单词游戏

PC/手机共用，保留扇贝插件。

- 英选中四选一，另有「不认识」，自动朗读。
- 选错、单题超时（默认20秒）或不认识均电击，不加码；原选项正确标绿、错选标红，不切换或滚动展示释义；10秒后下一题，可点或说「继续」提前进入；错词排当天队尾。
- 词库：高考、四级、六级、雅思，来源 ECDICT，跨库共用进度。
- 每日新词默认 20，另加到期复习；旧词当天首答对，间隔翻倍（1、2、4、8……不封顶），错回 1 天。
- 每词当天答对才完成。全部答对或整体时限到时解锁，未完成任务保留。
- 默认语音，说「第一个」至「第四个」选择，也可点选或关闭语音。
- 必须登录，进度云同步。
