# 背单词游戏新增日语 JLPT 词书

- 背单词游戏（`vocab-game`）内置日语 JLPT N5、N4、N3、N2、N1 五本词书，与原有高考/四级/六级/雅思英语词书在「更换词书」页分「英语」「日语」两组展示。
- 日语词卡下方直接显示假名读音（纯假名词不重复显示，不加音标斜杠），朗读自动切换为 `ja-JP`。
- PC 端与手机端（`control_panel_mobile`）同步更新词书资源，手机原生朗读桥 `DeviceAPI.speech.speak` 透传 `lang` 参数支持日文系统语音。
