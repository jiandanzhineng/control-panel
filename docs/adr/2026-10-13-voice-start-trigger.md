# 语音开始：口令触发玩法启动

类比设备按键开始，启动前选好触发方式，可指定麦克风；手机端也要实现。

用户决定：

1. 固定口令：中文「开始游戏」、英文「start the game」，两条同时生效，不让用户选。
2. 识别到口令直接开始，不加倒计时。
3. 远程会话首版不支持语音开始。
4. 识别模型用中英双语 KWS 模型 sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20。

实现细节见 docs/note/voice-start.md。
