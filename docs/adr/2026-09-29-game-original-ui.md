# 游戏使用原始 UI，不另做通用界面

用户指出为远程控制做的实现有偏颇：游戏应使用各游戏自带的 index.html 页面，而不是另搞一套 Vue 通用界面（gameSurfaces）；配置页也不应展示与实际运行界面不符的预览和「配置完成后将使用这个游戏界面运行」文案。

远程连接、授权、配置与控制仍放在独立工作区；运行页对本地与远程都渲染同一个游戏原始页面，宿主只负责导航、设备映射和远程会话。
