# 游戏语音识别：mimo 中转 SiliconFlow + 可自备 key

用户决定：

1. 游戏用的语音识别（首个使用者是朗读游戏）放到 mimo 中转，由中转持有 SiliconFlow key，客户端用账号登录换算力。
2. 用户也可以在面板「设置 → 语音服务」填自己的 SiliconFlow key，填了就直连 SiliconFlow，不经过中转。
3. 手机端同样支持这两种方式。

key 只存在本机设置或服务器环境变量，不进仓库。
