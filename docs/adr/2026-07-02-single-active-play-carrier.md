# 玩法运行唯一性：全局只有一个玩法，游戏与插件互斥

决定：全局同一时刻只允许一个玩法（游戏或插件）运行，两者互斥。启动新玩法时若已有玩法在跑，自动停掉旧玩法再启动，不拦不提示。

设备复位（硬约束）：任何玩法退出时、以及新玩法启动顶掉旧玩法时，必须对当次映射涉及的所有设备逐能力调 `stop`（`shock stop`、`strength stop` 等）。设备侧没有统一 close，「复位」就是逐能力 stop 的组合。

理由：物理设备同时被两个玩法驱动只会互相打架甚至叠加危险。自动顶掉最顺滑，强制复位避免旧玩法把电击开着就被切走。

后果：复位必须在玩法切换/退出的公共路径强制执行，异常退出、直接关页面也要兜底。若未来要多玩法并行，需改为按物理设备粒度互斥。
