# 运动心率电击提醒游戏

- 新增内置游戏「运动心率电击提醒」（`heart-rate-trainer`），接入心率传感器实时监测运动心率，心率低于设定下限时触发电击提醒。
- 支持设置心率下限、电击强度、电击持续时间、冷却恢复期、热身缓冲期与低心率容忍期等参数（高级参数折叠在高级设置中，不隐藏）。
- 采用独立后台托管核心（`runtime: "host"`，`game-core.js`），脱离页面或切后台时仍由宿主核心持续推进，PC 与移动端同步支持。
