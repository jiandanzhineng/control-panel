# 遥控车游戏规则

- 角色：A 遥控，B 趴地戴 DAN01、被 CUNZHI01 电击。远程时游戏在 B 端运行，语音在 B 端播。
- 指令：前进、后退、左转、右转，无「停」键。前进/后退按住须一直爬，松开即停，停后仍动也电。
- 前进判定：有爬行动作且朝向不偏，不测位移；后退同理。
- 转向：点一下须在反应时间 X 内朝该向转过 20°；按住时每个 X 秒窗口都须转过 20°。
- 惩罚：可设逐级加强，持续听话下降；A 可手动电击。
- 寸止、提肛为本游戏的附加规则，二选一。
- A 端以按钮为主，配状态显示。语音 AI 生成。
- 远程电压上限由 B 在远程设置里自设，默认 20、最高 100，A 改不了，游戏档位不越过它。
- 手机可作 A 端或 B 端（需补 DAN01 支持），B 端首期要求亮屏前台。
