# detector 注入：一次挂载 + detector 自决，浏览环境与内置浏览器共用

决定：

1. 一次挂载：webview 创建时挂上 detector 全程不动，detector 按 `matchUrls` 判断是否真正检测，非目标站自动装死；不用主进程动态挂卸。
2. 共用浏览环境：插件运行页 webview 与内置浏览器同一 partition，复用第三方站登录态。

理由：一次挂载没有动态挂卸的时序坑，逻辑直、易排查；共用登录态体验最省事。

后果：内置浏览器每个页面都会挂 detector，非目标站空跑不影响网页。这是已知取舍，由本机可信前提兜底。
