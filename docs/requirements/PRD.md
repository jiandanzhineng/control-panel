# 产品功能说明

本文按当前前端路由和后端实现整理，描述控制面板已落地功能。不再维护早期“空白占位页”PRD。

## 产品目标

控制面板用于在本机管理 UnderSilicon 设备、MQTT/mDNS 服务、玩法脚本、运行时页面、固件 OTA、日志和自动化测试。

## 页面范围

当前前端路由见 [项目架构说明](../architecture/ARCHITECTURE.md#前端页面)。

### 首页

首页提供快速入口：

- 设备管理
- 游戏管理
- 网络设置

同时展示系统信息：

- 在线设备静态统计（当前前端固定显示 0 台，尚未接入设备接口）
- 淘宝店链接
- 文档地址
- QQ 群

### 设备管理

设备管理页面提供：

- 设备列表、在线/离线状态。
- 设备类型名称展示。
- 设备昵称设置。
- 单设备删除、全部清空。
- 按设备类型展示可执行操作。
- 设备监控数据查看。
- 单设备 OTA 查询、状态订阅和升级。
- 跳转批量固件升级。
- 隐藏入口跳转自动化测试。

设备来自 MQTT 上报，后端会自动创建设备并维护在线状态。

### 批量固件升级

批量固件升级页面提供：

- 查询在线设备的最新固件信息。
- 批量下发升级到最新版本。
- 批量订阅 OTA 状态。
- 对已是最新固件的在线设备下发指示灯闪烁动作。

### 游戏管理

游戏管理页面提供：

- 游戏列表。
- 重新扫描 `backend/game/**/*.js`。
- 上传 `.js` 玩法文件。
- 删除玩法条目。
- 进入启动前配置。
- 停止当前运行玩法。

### 游戏启动前配置

启动前配置页面提供：

- 加载玩法元信息。
- 按能力筛选在线设备。
- 配置逻辑设备到实际设备的映射。
- 渲染玩法参数表单。
- 启动前校验阻塞项。
- 启动玩法后进入当前游戏页面。

已知缺口：页面的“恢复默认配置”会调用 `POST /api/games/:id/config/reset`，后端尚未实现。

### 当前游戏

当前游戏页面提供：

- 加载当前玩法提供的嵌入式 HTML。
- 执行玩法 HTML 中的脚本。
- 自动清理注入的 style、script 和 EventSource。
- 停止当前玩法并返回游戏列表。

玩法运行时详见 [游戏与玩法运行时说明](Game_Runtime.md)。

### 网络设置

网络设置页面提供：

- mDNS 启动、停止、状态轮询。
- MQTT Broker 启动、停止、状态轮询。
- MQTT 客户端状态展示。
- 底部实时日志，过滤 EMQX、MQTT、mDNS 相关模块。

当前 mDNS 启动不需要选择 IP，请求体不会被后端使用。

### 日志管理

日志管理页面提供：

- 实时日志流。
- 历史日志文件列表。
- 日志文件下载。

### 自动化测试

自动化测试页面提供：

- 启动/停止测试平台。
- 对在线设备按设备类型测试配置自动下发测试指令。
- 单设备重新开始测试。
- 通过 SSE 接收监控字段变化。

## 非功能要求

- API 以 `/api` 为统一前缀。
- 浏览器开发模式通过 Vite proxy 访问后端。
- Electron 模式通过 preload 和本地代理访问内置后端。
- SSE 页面离开时必须关闭连接。
- 设备控制和 OTA 下发必须通过后端 MQTT 客户端统一发布。
- 文档中的接口细节以 [后端 API 文档](../api/Backend_API.md) 为准。
