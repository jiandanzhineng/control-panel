# 游戏库页面重构（PC）

> 2026-11-08 用户要求：游戏列表页能力需求是英文、在线游戏衔接不流畅、缺设计感，重构该页并可调整游戏站嵌入方式。

## 现状问题

1. 卡片上的「需要设备」显示 `d.name || d.id`，而 manifest 里中文名在 `label`，所以出现 `shock` / `lock` 英文。
2. 本地游戏（`/plays`）与在线游戏（`/browser`，整页嵌入 game.undersilicon.cn）是两个菜单。在线站在 webview 里默认英文、深色站点风格和客户端割裂，选中游戏还要等顶部横幅再点「配置并运行」。
3. 卡片是标签堆叠（版本、来源、最后游玩全做成 tag），没有视觉层次；删除按钮和启动并列，过于显眼；工具栏常驻「停止当前运行」。

## 方案

### 信息架构

- 菜单「本地游戏」改名 **「游戏库」**（en: Library）；菜单「在线游戏」改名 **「游戏站」**（en: Game site），定位为社区/投稿/文档入口，不再是找游戏的主路径。
- 游戏库一页同时列出：本机游戏（内置 + 已保存）、在线游戏（`GET /api/game-registry`）、插件、本机应用（数字人）。
- 在线游戏在客户端原生渲染成卡片，点「开始」直接进配置页：`play_config` + `query.source=remote`（配置页已支持，首次自动下载缓存）。

### 合并规则（纯函数放 `frontend/src/play/library.ts`，带单测）

- 以游戏 `id` 合并本机与在线条目，一个 id 只出一张卡。
- 只在本机：状态「本机」。只在在线：状态「在线」，未缓存时按钮提示「首次启动自动下载」。
- 两边都有：本机版本 ≥ 在线版本 → 「本机」，从本机启动；在线版本更高（semver 比较）→ 「可更新 → vX」，「开始」走在线（source=remote），这样一点就是最新版。
- 在线库拉取失败：不报红色错误，筛选栏旁显示弱提示「在线库暂不可用」+ 重试；本机游戏照常显示。
- 排序：正在运行 > 最后游玩倒序 > 本机未玩 > 在线未装（按标题）；插件与本机应用放在游戏之后。

### 页面结构

1. **页头**：等宽小字眉标 `GAME LIBRARY`（沿用首页「硅基之下 · 控制中心」那种 eyebrow 风格），H1「游戏库」，一句副标题。右侧：「游戏站 ↗」按钮（跳 `/browser`）+「⋯」更多菜单（加载外部游戏 .js、开发指南、刷新）。
2. **焦点条**（二选一）：
   - 有运行中玩法：强调色描边面板，脉冲圆点 +「正在运行 · 标题」+「返回运行页」「停止」。
   - 否则若有最近游玩的游戏：「继续上次」横向卡（左侧封面、标题、相对时间如「3 天前」、「开始」）。
   - 都没有就不显示。原工具栏的「停止当前运行」删除。
3. **筛选栏**：分段筛选（全部 / 本机 / 在线 / 插件与应用，带数量），右侧搜索框（匹配标题与描述）。
4. **卡片网格**：`repeat(auto-fill, minmax(280px, 1fr))`，gap 16。

### 卡片解剖

- **封面**（高约 112px）：按 id 哈希出色相的柔和渐变 + 细网格/点阵纹理 + 标题首字大号半透明字形；左上角状态徽标（本机 / 在线 / 可更新 vX / 运行中），右上角「⋯」菜单（在游戏站查看〔在线条目〕、删除〔本机游戏〕）。插件与本机应用用不同的封面底纹与图标区分。
- **正文**：标题单行省略；描述最多 2 行省略；设备需求 chips：显示设备角色 `label`（已按 locale 本地化），没有 label 时用能力中文名（`playConfig.caps.*`），必需实心、可选描边，hover 提示该角色需要的能力（中文，隐藏 `reporting`）。最多 4 个，多余「+n」。
- **底栏**：左侧等宽小字 `v1.1.13 · 3 天前玩过`（或「从未游玩」/「在线 · 12 KB」）；远程延迟标签（runtimeTag）保留为小字；右侧主按钮「开始」。整卡可点（等同开始），按钮和菜单阻止冒泡。
- hover：轻微上浮 + 边框转强调色；暗色/亮色两套主题都只用 `style.css` 里的 token。

### 本机应用卡

`LocalAppCard.vue` 改成同样的封面/正文/底栏结构，安装/更新/启动逻辑不动。

### 游戏站（BrowserView）调整

- 跟随客户端语言：webview `dom-ready` 时若页面是游戏站 origin，读站点 `localStorage['site-locale']`，与客户端 locale 不同就写入并 reload 一次。
- 支持 `route.query.url` 直接打开指定页面（游戏库「在游戏站查看」→ `game-intro.html?id=<id>`）。
- 工具栏加「返回游戏库」。

### 文案

所有新文案进 `i18n/locales/zh.ts` 与 `en.ts`，能力名补齐常用项。首页卡片「本地游戏」同步改为「游戏库」。

## 不做

- 不改游戏运行页、配置页逻辑（ADR 2026-09-29：游戏用原始 UI）。
- 不改 play-registry 站点本身。
