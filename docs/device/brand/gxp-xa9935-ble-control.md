# GXP 艾萝机娘二代 BLE 控制说明

对照 `GXP-Windows-v0.5.1` 的 BLE 控制协议。展示名「gxp艾萝机娘二代」。

## 扫描与 GATT

- 广播名默认含 `Xa9935`（不区分大小写，部分匹配）。
- 控制写 `0000FF03-0000-1000-8000-00805F9B34FB`，Write With Response。
- 状态通知 `FF02`，连接后订阅，不解析成闭环。
- `FF01` 不作为控制通道。
- 设备没有本面板的 `FF04` 身份特征，设备 ID 用 12 位小写 BLE MAC。

## 已确认字段

- 往复电机：payload 百分比 0–100。面板 `strength` 对外 0–255，换算 `round(power/255*100)`。
- 震动模式：1–12，写入 `100+mode`；0 表示不带模式。
- 停止震动：独立 0x03 帧，payload[2]=`07`。不是电机归零。

## 不要写

震动马达强度没有已确认字段，品牌页不提供该滑条，能力层也不暴露 `vibration` 强度。

## 控制面板映射

- 类型 `GXP_XA9935`，品牌 `gxp`。
- 玩法只走 `strength`。
- 品牌页可试控电机、震动模式、停止震动。
- 断开/关闭：电机 0，再发停止震动。
- 产品路径：本机桥（`ycy_bridge` 端口 3001）写 `FF03`。
